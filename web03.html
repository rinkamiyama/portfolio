Title

Pattiserie 白樺

Category

Web Design / Logo

Software

Adobe Photoshop / Visual Studio Code

Technology

HTML / CSS / JavaScript

Description

「牧場 × 森」をコンセプトに、北海道にあるパティスリーサイトのトップページを担当し、デザインカンプからワイヤーフレーム、コーディング実装までを制作。白樺の森や北海道産素材の魅力が伝わる、落ち着いた雰囲気にまとめた。PC画面では1画面内で情報を把握しやすいよう、余白や配置、情報量のバランスを意識。統一感を持たせながらも、カテゴリごとにレイアウトや見せ方を変え、スクロールしても単調にならない構成にし、スマホ版レスポンシブにも対応。ロゴは白樺の木の質感とパティスリーをイメージした屋根のモチーフを組み合わせ、ブランドの世界観を表現。
